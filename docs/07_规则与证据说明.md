# 规则与证据说明

规则实现位于 scripts/pipeline.py。风险分数仅为课程原型审阅优先级。

| 规则 | 条件 | 分值 | 局限 |
|---|---|---|---|
| rate_surge | 至少3个过去轮次，当前至少5条消息；窗口速率大于 max(过去轮次速率中位数×3, 2/h) | 45 | 日轮次转小时轮次会影响基线；不能视为真实活跃度突变证明 |
| new_public_channel | Agent已有至少10条历史消息，首次使用某公开渠道 | 40 | 仅限已观测历史 |
| named_public_before_formal_lift | 公开渠道、命中 HarborCrest/CivicLoom/ResidentEdge、早于明确完成的正式解禁消息 | 85 | 同意或先期第三方公开仍需核验，不自动等同违规 |
| named_public_topic | 实体关键词命中且公开，无早于正式标记条件 | 30 | 仅关键词筛选 |
| decision_during_unavailability | 轮次环境有不可用人员且命中主题，并有公开动作或发布/授权等决策动词 | 70 | 可能其他监控仍可用，不证明监控完全失效 |

证据等级：fact_record 表示“该文本在数据中被记录”，并不验证文本声称的现实真伪。inference_reply 只表示主题消息间存在时间有效的回复引用。确证因果/传播路径目前不自动输出。

通信边分 recipient 和 reply。所有边 propagation_confirmed=false；时序错误的回复保留在审计表且 temporal_valid=false。ALL 不展开、不建虚拟节点。网络不展示自环。缺失接收人与 @文本不补猜。

实体筛选会漏掉只含 @ElenaMarquez 等间接信号；例如 20460529_08_013 是 5月29日个人发帖事件的内部自述，不能据它生成不存在的公开记录。应与同轮外部叙事并列阅读。

时间：官方数据没有时区。environment_context 的条目使用轮次起点、标注 round 精度；正文中的时间和情境预测不会被当作新的精确事件。末轮窗口至最后一条消息，并非完整一小时。

来源定位：原始文件 data/raw/VAST_Challenge_2026_MC1/MC1_final_00.json；所有消息和状态保存相对文件名及 JSON Pointer。官方说明文件名和结构示例与真实文件不一致，实际结构以画像为准。

整轮速率候选的支持集合是该 Agent 在该轮全部消息，不只首条。图表全局筛选、边联动、消息详情 API 和“异常候选关联消息”均使用支持集合交集；首条 message_id 只作候选稳定定位。整体消息速率采用所有轮次窗口总时长作共同分母；历史基线的零记录轮次不等于真实空闲。全局角色筛选是发送者筛选，不代表其全部收发通信。

具体可复核事件摘录见 reports/harborcrest_findings.md。
